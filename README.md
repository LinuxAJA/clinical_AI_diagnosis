# Diagnotico IA Clinico

#### A guided machine learning pilot project for educational purposes

## Deploy

Link: [clinical-ai-diagnosis.streamlit.app](https://clinical-ai-diagnosis.streamlit.app/)

## Steps to execute in local

### Create Virtual Environment

```Shell
cd modelos_ML/random_forest
python -m venv .venv
.venv/Scripts/activate
```

### Install Libraries

```Shell
pip install -r requirements.txt
```

### Execute in local

```Shell
streamlit run 3.Predecir_enfermedad.py
```
